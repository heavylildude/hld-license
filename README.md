A permissive, open-source license derivative of the MIT License, optimized for sharing documentation, data structures, and informational knowledge.

## Why HLD License 1.0?
Traditional open-source licenses like MIT, Apache, or GPL are legally hardcoded for "software" and "source code." The HLD License replaces software-centric terms with **"Knowledge"**, making it perfect for:
* Technical documentation and wikis
* Data schemas, models, and JSON structures
* Conceptual frameworks and educational materials

## How to Use This License

If you want to protect your project using the HLD License 1.0, follow these two simple steps:

### Locally
1. Copy the full text from the `LICENSE.md` or the `LICENSE.txt` file in this repository.
2. Paste it into a file named `LICENSE` or `LICENSE.md` or `LICENSE.txt` at the root of your own project.

### CDN
1. Add either:
   - `https://cdn.jsdelivr.net/gh/heavylildude/hld-license@main/LICENSE.md`
   - `https://cdn.jsdelivr.net/gh/heavylildude/hld-license@main/LICENSE.txt`
   
   directly in your file
2. That's all! The cdn has common attribution of Copyright (c) The respective authors and contributors of the Knowledge.

### Quick Attribution (Optional)
You can also add this notice to the top of your files or your project's README:
```text

```
